What is Local DeepWiki?

Local DeepWiki generates comprehensive documentation for your private repositories, keeping everything on your machine. It combines tree-sitter parsing, semantic code chunking, and LLM-powered wiki generation.

  • Multi-language AST parsing with tree-sitter
  • Semantic code search with vector embeddings
  • RAG-based Q&A with conversation history
  • Deep research with multi-step reasoning
  • Interactive codemap visualization
  • API docs, call graphs, inheritance trees
  • Privacy-first: everything runs locally

Get Started

To view your wiki, you need to index your repository first.

1 Open MCP Client (Claude Desktop, Cline, etc.)
Make sure Local DeepWiki MCP server is configured in your client.
2 Index Your Repository
Ask Claude to run the index_repository tool:
index_repository(repo_path="{{ wiki_path }}")
This will parse your code, generate embeddings, and create wiki documentation.
3 Refresh This Page
Once indexing completes, refresh your browser to see the wiki.

Alternative: CLI Commands

You can also use the CLI for indexing and auto-reindexing:

Index once:
uv run local-deepwiki
Or watch for changes and auto-reindex:
uv run deepwiki-watch {{ wiki_path }}

Learn more in the documentation.
